Guide & Glossary

Action Colors
Yellow — Additive / Enable
Adds an item to the whitelist, enables a module or boot script, or increases a numeric setting (timeout, threshold, stability time).
Red — Remove / Disable
Removes an item from the whitelist, disables a module or boot script, or decreases a numeric setting.
Orange — Mixed Batch
Multiple queued changes that combine both additions (enable/whitelist) and removals (disable/unwhitelist) in a single save.
Item Tags
MOD
Magisk / KSU Modules
Standard root modules loaded by your manager.
SVC
Service Scripts
Scripts executed late in the boot process (service.d).
PMD
Post-Mount Scripts
Manual only. Executed early during boot (post-mount.d). Cannot be auto-protected.
PFD
Post-Fs-Data Scripts
Manual only. Executed early during boot (post-fs-data.d). Cannot be auto-protected.
